## 하는 법
`~/.zshrc` 는 터미널을 열 때마다 자동으로 실행되는 설정 파일입니다. 여기에 한 줄을 넣으면 새 터미널마다 `gh` 가 키체인에 보관한 토큰을 꺼내 `GITHUB_PAT` 에 넣어 줍니다. 토큰 값 자체는 파일에 남지 않습니다.

**① 터미널에서 아래 한 줄을 그대로 붙여 넣고 Enter**
```zsh
echo 'export GITHUB_PAT="$(gh auth token 2>/dev/null)"' >> ~/.zshrc
```
- 바깥 작은따옴표(`'...'`)를 꼭 지켜 주세요. 작은따옴표 덕분에 지금 토큰 값이 파일에 박히지 않고, "토큰을 꺼내는 명령"만 파일에 들어갑니다.
- `>>` 는 파일 끝에 덧붙이는 기호입니다. `>` 하나로 쓰면 기존 내용이 지워집니다.

**② 들어갔는지 확인(토큰은 화면에 나오지 않습니다)**
```zsh
source ~/.zshrc && [ -n "$GITHUB_PAT" ] && echo "GITHUB_PAT 설정됨"
```
`GITHUB_PAT 설정됨` 이 나오면 됩니다. `echo $GITHUB_PAT` 처럼 값을 직접 찍는 것은 피해 주세요. 화면에 나온 내용이 세션 로그에 남을 수 있습니다.

**③ VS Code 를 완전히 종료(⌘Q)했다가 다시 열기**
VS Code 는 시작할 때 환경 변수를 읽기 때문에 창만 다시 열어서는 반영되지 않습니다. 다시 열면 이 작업 공간에서 새 Claude 세션을 시작하고 `/mcp` 를 입력해 `github` 서버를 승인해 주세요.

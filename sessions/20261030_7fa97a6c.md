## Unity CLI 와 다른 점

| | Unity CLI | Blender CLI |
|---|---|---|
| 방식 | 에디터를 띄워 두고 `unity command` 로 계속 조작 | 실행할 때마다 Python(`bpy`) 스크립트 한 번 돌리고 끝남 |
| 상태 | 에디터에 씬이 열린 채 유지됨 | 매번 새로 시작. 이어서 하려면 `.blend` 를 열고 저장 |
| 결과 확인 | 콘솔과 게임 뷰 | 렌더한 PNG 를 제가 열어 봄 |
| 추가 설치 | 공식 플러그인 | 없음. Blender 에 기본으로 들어 있음 |

포트폴리오에는 오히려 좋은 점이 있습니다. 모델 하나가 **스크립트 하나**가 되니 git 에 소스로 남고, 다시 만들 수 있고, 리뷰도 할 수 있습니다. 「코드로 만든 로우폴리」라는 직접 제작 근거가 됩니다.

단점은 하나입니다. 작업 중에 사용자가 Blender 화면으로 실시간으로 볼 수 없습니다. 나중에 `.blend` 를 GUI 로 열어 보는 것은 됩니다.
